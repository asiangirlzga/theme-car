# Lite Racer Kids (Android TV / Android)
Kid-friendly (6+) racing game. No libraries, no image files -> tiny APK, very low RAM.

Controls (TV remote):
- LEFT / RIGHT : steer (or choose a world on the start / end screen)
- UP (hold)    : go faster
- DOWN (hold)  : slow down
- OK           : start / pause / play again

Worlds: Meadow, Desert, Snow, Space. 3 hearts, collect stars, cute cartoon cars.

Build: push to GitHub -> Actions -> "Build APK" -> download artifact `LiteRacer-apk`.
